开发者更新规则

  • 更新清单修改 dev/update.json 的 version、releaseDate 和 notes 后提交到网站仓库。
  • 版本比较开发者版启动器会把当前版本与清单版本比较，发现新版本时显示更新提示。
  • 发布范围此页面和开发者版构建仅用于内部测试，不作为正式用户下载入口。

如需修改访问密码，更新本页中的密码哈希即可。静态页面的密码保护只能阻止普通访问，不能替代服务器端鉴权。
