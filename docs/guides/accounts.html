账户与登录

管理 Microsoft 正版账户、离线档案和第三方验证账户，启动前选择本次使用的身份。

入口：左侧 账户 → 添加账户

操作步骤

  1. 添加 Microsoft 账户点「添加账户」选择 Microsoft，浏览器会打开微软登录页，授权后回到启动器。
  2. 添加离线档案选择「离线」，输入游戏内用户名。离线档案不需要密码，也不能访问正版服务器。
  3. 第三方验证如果服务器使用第三方验证，选择对应方式并按提示填写验证地址和凭据。
  4. 设为当前账户在账户列表里选择要使用的账户，主页和启动按钮会显示当前身份。
  5. 检查皮肤正版账户登录后，皮肤和披风会跟随账户；离线档案使用本地皮肤设置。
账户安全：启动器不会保存你的 Microsoft 密码。不要把账户令牌、验证码或第三方凭据发给别人。

注意事项

  • 离线用户名不能用于需要正版验证的服务器。
  • Microsoft 登录需要浏览器完成授权；如果浏览器没有自动回到启动器，重新点一次登录。
  • 多个账户可以同时保存，启动前确认选中的是正确账户。

常见问题

微软登录一直转圈？

检查默认浏览器和网络；关闭拦截弹窗的扩展后重试。

离线用户名能用中文吗？

建议使用英文、数字和下划线，避免服务器或皮肤系统不兼容。

皮肤没有同步？

确认当前是 Microsoft 账户且登录成功；离线档案只显示本地皮肤。
