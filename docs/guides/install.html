游戏安装与启动

从零安装一个 Minecraft 版本，或者给已安装版本补上 Forge、Fabric、NeoForge、Quilt 加载器。

入口：左侧 下载 → 游戏版本

操作步骤

  1. 选择游戏版本打开「下载」→「游戏版本」，在版本列表里找到要玩的 Minecraft 版本。
  2. 下载原版点「下载安装」。启动器会下载游戏文件、资源索引和运行库，进度显示在按钮和状态文字里。
  3. 需要模组时安装加载器如果这个版本要装模组，点「安装选项」或加载器入口，选择 Forge、Fabric、NeoForge 或 Quilt，并确认加载器版本与游戏版本匹配。
  4. 检查已安装切到「已安装」，确认新版本出现在列表里。每个版本都有独立的模组和配置目录。
  5. 启动游戏回主页选择版本，必要时先在「设置」里指定 Java 和内存，再点「启动游戏」。
版本隔离：原版、Forge、Fabric 和整合包会各自使用独立目录，装模组时不要混到别的版本里。

注意事项

  • 新版本通常需要 Java 17 或 21；启动前在设置页确认 Java 已被识别。
  • 加载器必须和游戏版本对应，例如 Fabric 1.21.1 不能装到 1.20.1。
  • 安装失败时先看「日志」页的错误输出，再检查网络和磁盘空间。

常见问题

点下载后没有反应？

确认网络可访问资源站；切换页面再回来，或查看日志页是否有下载错误。

Java 显示未检测到？

在「设置」里手动选择 Java 可执行文件。新版 Minecraft 通常需要 Java 17 或 21。

启动后退回启动器？

打开「日志」查看崩溃原因，常见是 Java 版本不对、内存过大或模组冲突。
