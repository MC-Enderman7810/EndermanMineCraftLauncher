整合包

导入 PCL2、Modrinth 或 CurseForge 整合包，作为独立实例启动，不覆盖现有版本。

入口：左侧 整合包 → 导入整合包

操作步骤

  1. 准备整合包下载整合包压缩包，或准备已经解压的整合包文件夹。
  2. 选择导入方式在「整合包」页点「导入整合包」，选择 zip 或文件夹。
  3. 确认实例信息启动器会读取整合包内的版本、模组和配置。给它一个容易辨认的名称。
  4. 等待安装确认后等待文件复制和依赖检查完成；大整合包需要更长时间。
  5. 启动实例在整合包列表里点启动。它会使用自己的目录，不会影响正式版或其他版本。
不要直接覆盖：导入会创建独立实例。想更新整合包时，先备份存档，再导入新版本。

注意事项

  • 整合包自带模组和配置，不要随意把别的模组装进去。
  • 大型整合包建议分配 4GB 以上内存，并确认 Java 版本符合要求。
  • 整合包内的授权和模组版权归原作者，启动器只负责本地导入和启动。

常见问题

导入后启动崩溃？

先看日志页；常见原因是内存不足、Java 版本不匹配或整合包文件不完整。

能导入 PCL2 的整合包吗？

可以，启动器支持读取 PCL2 整合包结构；无法识别时会提示缺少的文件。

整合包更新会覆盖存档吗？

不会自动覆盖。更新前请先备份存档目录。
