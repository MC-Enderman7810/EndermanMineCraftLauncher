资源下载

在启动器里搜索模组、光影、资源包和数据包，按当前版本与加载器筛选后直接安装。

入口：左侧 下载 → 资源下载，先选一个已安装版本

操作步骤

  1. 选择目标版本在右上角版本下拉框选择要安装资源的版本。过滤条件会跟随这个版本的游戏版本和加载器。
  2. 选择资源类型用标签切换「推荐」「模组」「光影」「资源包」「数据包」「整合包」。
  3. 搜索并选择文件输入名称搜索，进入资源详情，选择与你的游戏版本、加载器匹配的文件。
  4. 安装点「安装」。模组、光影和资源包会放入当前版本的对应目录；数据包会安装到所选存档的 datapacks 目录。
  5. 重启游戏安装完成后完全退出游戏再启动，让新资源生效。
数据包需要先选存档：安装数据包前，在数据包页选择目标存档，否则不会写入正确的世界目录。

注意事项

  • 模组必须匹配游戏版本和加载器；光影还需要对应的光影加载器。
  • 启动器会显示来源和筛选条件，安装前确认文件支持你的环境。
  • 一次不要装太多模组，出现冲突时用日志排查。

常见问题

搜索不到某个模组？

检查资源类型和版本筛选；有些项目只支持特定加载器或游戏版本。

安装后游戏里没有？

确认安装到了当前启动的版本；模组需要对应加载器，资源包需要在游戏内启用。

数据包没有生效？

确认安装时选对了存档，并在游戏内用 /datapack list 检查。
