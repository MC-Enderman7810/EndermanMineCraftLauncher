本地服务器

管理本地 Java 服务端、远程 RCON 和 MCSManager 面板，启动、停止、看控制台、改属性、备份和分析。

入口：左侧 服务器

操作步骤

  1. 本地服务端点「添加本地服务端」，选择已有的 server.jar 所在目录；启动器会读取服务端类型和配置。
  2. 生成服务器没有服务端时点「生成服务器」，按向导选择版本和加载器，启动器会下载并生成基础文件。
  3. 远程 RCON点「添加远程 RCON」，填写主机、端口和 RCON 密码，用于管理远程服务器。
  4. MCSManager需要面板时点「安装 MCSManager」或「MCSManager 面板」，按提示安装并打开。
安全：不要把 RCON 端口直接暴露到公网；远程管理建议使用隧道或只允许可信 IP。

注意事项

  • 启动 / 停止：在服务器卡片右侧操作；停止前先保存世界。
  • 控制台：输入 list、say 等命令，输出会实时显示。
  • 属性：修改 server.properties，保存后重启生效。
  • 备份：创建世界备份，升级或换模组前先备份。
  • 玩家：查看在线玩家并执行管理操作。

常见问题

启动提示端口被占用？

修改 server.properties 的 server-port，或关闭占用该端口的程序。

RCON 连接失败？

确认远程服务端已开启 enable-rcon、端口和密码一致，并检查防火墙。

服务端卡顿？

检查内存分配、视距和实体数量；备份后再调整配置。
