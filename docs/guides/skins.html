皮肤与披风

正面预览皮肤，切换 Steve / Alex 模型和衣层，选择推荐皮肤、上传本地皮肤并切换披风。

入口：左侧 皮肤 → 选择当前账户

操作步骤

  1. 选择账户在皮肤页顶部确认当前账户。正版账户会读取官方皮肤，离线账户使用本地设置。
  2. 切换模型在 Steve / Alex 之间选择，预览会立即更新。
  3. 调整衣层用衣层开关显示或隐藏帽子、外套、袖子、裤子和鞋子。
  4. 选择推荐皮肤在推荐列表里点一款皮肤应用；也可以上传本地 PNG 皮肤文件。
  5. 切换披风如果账户有可用披风，在披风列表里选择并应用。
  6. 确认效果正面预览确认外观后启动游戏；服务器是否显示取决于服务器和账户验证。
本地皮肤：上传的皮肤先保存在本地。离线档案可以使用本地皮肤，但正版服务器可能不显示。

注意事项

  • 皮肤文件使用 Minecraft 标准 PNG 格式，建议 64×64。
  • 披风通常需要正版账户和官方披风资格。
  • 衣层设置只影响预览和本地显示，不会修改服务器规则。

常见问题

上传皮肤失败？

确认文件是 PNG 且尺寸正确，文件名不要包含特殊字符。

游戏里看不到皮肤？

检查账户是否正版登录，以及服务器是否使用正版验证。

换了模型没变化？

确认应用后重新启动游戏；部分服务器会缓存皮肤。
