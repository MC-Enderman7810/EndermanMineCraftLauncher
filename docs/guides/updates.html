公告、更新与反馈

了解自动更新、三个更新通道和反馈流程。

入口：主页公告、更新提示、左侧 设置 中的刷新，以及应用内 反馈 按钮

操作步骤

  1. 启动时自动检查启动器启动后会读取公告和更新清单；有新版本时显示更新提示。
  2. 手动刷新在公告/更新入口点「刷新公告和更新」，重新拉取最新内容。
  3. 查看版本说明更新提示里会显示版本号和更新内容；确认后再下载。
  4. 安装更新按提示下载并替换当前版本；更新前关闭正在运行的游戏。
  5. 反馈问题点应用内「反馈」，会打开网页反馈表单，自动带上应用名和版本号。
反馈需要邮箱：网页表单要求填写邮箱，方便回复；邮箱不会公开。提交后会进入开发者反馈收件箱。

注意事项

  • 正式版：稳定功能，更新源为 emcl.life/update.json。
  • 商弦特供版：独立主题与入口，更新源为 emcl.life/sianhgheln/update.json。
  • 开发者版：内部测试，更新源为 emcl.life/dev/update.json。

常见问题

检查不到更新？

确认网络能访问 emcl.life；当前版本已经是最新时不会提示。

公告是空的？

可能是网络或公告源暂时不可用，稍后刷新；也可以直接打开公告页。

反馈提交失败？

检查邮箱格式和网络；稍后重试，或直接发邮件到 EMCLsupport2026@163.com。
