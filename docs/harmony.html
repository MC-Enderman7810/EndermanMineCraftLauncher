EMCL 鸿蒙版

面向 HarmonyOS 手机、平板和鸿蒙电脑的 Minecraft Java 版启动器。基于 ArkTS 原生界面，保留 Java 运行时、版本安装、模组、整合包、账户、皮肤、服务器和日志能力。

当前为未签名测试构建。
鸿蒙手机/平板和鸿蒙电脑 HAP 不能直接安装到真机。需要先在 DevEco Studio 中配置签名，或使用 DevEco 模拟器运行。正式上架包会在华为 AppGallery Connect 完成发布签名后提供。
