三步，进入世界。

不用折腾启动脚本和 Java 参数。装好 EMCL，剩下的交给它。

登录账号

使用 Microsoft 账号登录，或创建离线档案。皮肤和披风会随账号同步。

选择版本

原版、Forge、Fabric、NeoForge 或整合包。缺失的文件会自动下载。

开始游戏

调整内存和 Java，点下启动。模组、光影和服务器设置都会保留。

定制版本

让你的服务器拥有专属启动器
