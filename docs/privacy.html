隐私政策

生效日期：2026-10-24

EMCL Studio（以下简称“本应用”）是一款本地优先的 Minecraft Java 服务器与创作工具。我们尽量让数据留在你的电脑上。

1. 我们处理哪些数据

  • 账户信息：当你使用微软账户登录时，本应用会处理你的 Xbox/Minecraft 标识符、Minecraft 名称、UUID 和公开皮肤。我们不会获取或保存你的微软密码。
  • 本地配置：游戏目录、Java 路径、内存设置、服务器配置、日志和备份保存在你的本机。
  • 日志：启动器/服务端日志可能包含设备、Java 版本、模组列表和错误信息。提交错误报告前会自动移除 JWT、access token、refresh token 等敏感字符串。
  • 网络请求：读取 Mojang/BMCLAPI 版本清单、Modrinth 项目与更新公告时，会向相应服务发送必要的 HTTP 请求，包括 IP 地址和 User-Agent。

2. 账户令牌

微软/Xbox 的 access token 和 refresh token 只保存在本机，使用 Windows DPAPI 加密（或仅限当前用户可读的本地存储）。我们不会把令牌上传到 EMCL 服务器。

3. 我们不做什么

  • 不出售、出租或交换你的个人数据。
  • 不收集与功能无关的键盘输入、屏幕内容或通讯录。
  • 不把账户令牌发送给第三方广告或分析服务。

4. 第三方服务

本应用可能访问 Microsoft 登录、Xbox Live、Minecraft Services、Mojang/BMCLAPI、Modrinth 和 GitHub。它们各自有自己的隐私政策。你使用这些服务时，同时受其条款约束。

5. 数据保留与删除

本地数据由你控制。你可以在应用内删除账户、日志、服务器配置和备份，也可以直接删除应用数据目录：

%APPDATA%\emcl-launcher（发布版）
%APPDATA%\emcl-launcher-dev（开发者版）

如需协助删除数据，请联系支持邮箱。

6. 儿童

本应用不面向 13 岁以下儿童。若你是未成年人，请在监护人同意下使用，并遵守 Minecraft 与 Microsoft 的账户年龄要求。

7. 安全

我们采用最小权限、日志脱敏和本地加密等措施，但任何软件都无法保证绝对安全。请保护你的 Microsoft 账户，开启两步验证，不要分享密码或令牌。

8. 政策更新

我们可能更新本政策。更新后会修改生效日期，并在本页面发布。继续使用即表示接受更新后的政策。
