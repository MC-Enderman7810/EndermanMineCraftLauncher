安装说明

下载后直接运行，不需要安装。首次启动会创建独立数据目录，不会影响已经安装的 EMCL 标准版。

未签名 EXE 可能触发 Windows SmartScreen：点击「更多信息 → 仍要运行」即可。

自动更新：启动器会从 https://www.emcl.life/sianhgheln/update.json 检查商弦特供版更新，不会读取标准版更新清单。

需要拥有 Minecraft: Java Edition 的微软账户才能在线游戏。EMCL 不包含游戏本体。
